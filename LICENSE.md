# Licença e origem

Open Geometry Wars (OpenGW) foi criado por Peter Hirschberg. A base deste port é
o código OpenGW r42. O projeto original declara GNU General Public License
version 3.0 (GPLv3) em https://sourceforge.net/projects/opengw/.

O código do jogo e estas adaptações são distribuídos sob GPLv3; consulte COPYING.
Os avisos de autoria e licença dos componentes de terceiros permanecem válidos:

- LodePNG: licença zlib, no cabeçalho de lodepng.cpp e lodepng.h.
- GLEW: avisos e licenças em GLEW/LICENSE.txt.
- SDL original incluído no código legado: SDL/COPYING.txt.
- SDL2-compat e SDL3 dos aplicativos macOS: licenças incluídas em
  OpenGW.app/Contents/Resources/Licenses/ nos pacotes de distribuição.
- GL4ES do pacote RGB30: licença MIT incluída em opengw/gl4es.aarch64/LICENSE.

O pacote macOS e o pacote RGB30 incluem a licença do jogo. O código correspondente
é disponibilizado neste repositório. As bibliotecas SDL atuais e GL4ES não são
incorporadas ao histórico Git como executáveis; ficam nos pacotes de Release.
